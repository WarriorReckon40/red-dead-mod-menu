## 🧩 About

**Red Dead Redemption 2 Companion** is a curated list of Red Dead Redemption 2 open-source tools:

- **Overlays** — on-screen helpers, layout notes, stat readouts, menu panels
- **Quality-of-Life Helpers** — inventory notes, horse manager, config presets
- **Research Notes** — mission layouts and config notes for educational use

Based on publicly available community tools and overlay helpers.

## ✨ Features

### ESP
- Menu Panel — toggle in-game overlay with configurable hotkey
- Stat Readout — display health, stamina, and dead-eye notes on screen
- Route Notes — record and review mission paths
- Time Control Notes — adjust world pacing for study (0.1x to 5x)

### Wallhack
- Outfit Catalog — browse clothing, colors, and gear notes
- Weapon Notes — organize loadout presets
- Horse Manager — track stables, saddles, and bonding notes

### Aimbot
- Map Overlay — annotate points of interest for study
- Inventory Notes — segment study on any layout
- Fast Travel Notes — plan routes in the editor
